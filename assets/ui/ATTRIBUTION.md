# UI 素材来源与许可说明

本目录下的第三方开源素材及其许可证如下，二次创作素材（`decor/`）为本项目原创，可自由使用。

## icons/ancient/ （古风剪影图标）

- 来源：[game-icons.net](https://game-icons.net/)（仓库：`github.com/game-icons/icons`）
- 许可证：**CC BY 3.0**（https://creativecommons.org/licenses/by/3.0/）
- 作者：Lorc、Delapouite、Skoll、DarkZaitzev 等（game-icons.net 署名作者群）
- 本项目改动：移除了 SVG 自带的黑色背景矩形，并将填充色由白色改为墨色（#2c2c2c）
- 使用清单：sword/battle/book/broom/anvil/explore/scroll/bounty/dice/coins/meditate/run/calendar/bag/talk/gear/save/hourglass/gate/mountains/yinyang/lantern/pagoda/fist/map/lotus/crane/farm/cauldron

## icons/flat/ （扁平线性图标）

- 来源：[Remix Icon](https://github.com/Remix-Design/remixicon)
- 许可证：**Apache License 2.0**
- 未作修改，仅重命名文件以便维护
- 使用清单：user/team/bag/settings/save/history/sword/book/compass/hammer/run/calendar/heart/coins/dice/back/skip/gate/chat/quill/map/edit/eye/refresh/farm/flask

## decor/ （中式纹样装饰）

- `corner-huiwen.svg`（回纹边角）、`cloud-divider.svg`（祥云分隔带）、`ink-mountain.svg`（淡墨远山）
- 本项目原创绘制，灵感来自中国传统公有领域纹样，可自由使用

## 字体（assets/fonts/）

- 来源：[google/fonts](https://github.com/google/fonts) 开源字体仓库，许可证均为 **SIL Open Font License 1.1**
- `zcool-xiaowei.ttf`（站酷小薇 ZCOOL XiaoWei）：古风正文/界面字
- `ma-shan-zheng.ttf`（马善政毛笔体 Ma Shan Zheng）：古风标题书法字
- `zcool-qingke-huangyou.ttf`（站酷高端黑 ZCOOL QingKe HuangYou）：印章字
