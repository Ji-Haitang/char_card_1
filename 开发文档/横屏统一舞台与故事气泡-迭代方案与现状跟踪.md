更新：2026-11-19 · 分支：`refactor/unify-stage-renderer` · 游戏代码基线：`ce7afd3`

**当前进度：P6 手机横屏纸框与防误触，已通过本地浏览器验收。** 短句工具用圆形图标，浮在等宽气泡的左上边缘；全文／输入时收进框内。发送时上一幕和正文保持可见。竖屏沿用原正文和原输入；安卓真机 IME 待验。

## 一、玩家旅程与交互规则

横屏只使用一个主视窗。演出时在画面上读故事，门派操作时直接使用地图或所在地点；不再进出独立绘卷，也不再维护两份当前位置。以下是目标行为。

| 玩家所在位置 | 怎么操作 | 预期反馈 |
|---|---|---|
| 有演出帧，阅读本轮 | 点击底部半透明气泡的左、右区域 | 按短句翻页；同段沿用表情和 CG，跨段按新段更新。首页不后退；GM0 末句再右翻回到操作层，GM1 和必须处理选择时停在末句。 |
| 想通读或查上轮 | 点击气泡上沿便签，展开全文；上下滚动，左右切历史回合全文 | 全文可以占满舞台。收起后回到进入全文前的本轮短句，翻历史不改本轮进度。 |
| 没有可演出的帧 | 新回合默认在操作场景上叠加**展开全文**的气泡 | 无场景、立绘也能读、输入和处理事件，不为显示文字制造空演出。 |
| GM0 想操作门派 | 普通演出时点工具栏安全区以外的画面；气泡内也有「返回操作」，全屏全文时仍可点 | 隐藏气泡并显示地图或所在地点。操作层左下角出现书本按钮，点击返回故事；同回合恢复阅读位置，无帧回合返回全文。 |
| GM1 下山 | 演出中直接用齿轮、任务等入口；不显示 GM0 的「返回操作」 | 不切到门派地图。「返回门派」走齿轮内原业务入口，「游戏设置」从系统设置进入。 |
| 想输入行动 | 点气泡内输入按钮，用原输入框和「发送／重生成」替换正文，再点切回 | 切换本身不发送、不清草稿；选字、编辑及点击按钮不触发翻页。保留原禁用条件和生成中的中断入口。 |
| 想调设置、看图或重听 | 气泡内左上角放齿轮、任务 `!`、观景等工具；重读、语音也从气泡进入 | 工具栏固定在滚动正文之外，展开全文仍能操作。观景在演出时隐藏气泡和工具，保留场景、人物及 CG；再点画面只恢复原界面，不连带退出演出。操作层无气泡时，保留视窗工具和原观景行为。 |
| 本轮有随机事件 | 全文模式中，事件说明与选项接在**同一滚动区的正文末尾** | 滚到底即可处理，选项只执行一次。历史全文只读；不把当前可提交的事件挂到旧回合。非展开态也要有可发现的事件入口。战斗、支线仍遵从各自原有流程。 |

输入、工具、事件、弹窗的点击由对应控件处理；只有未被控件使用的演出背景点击才可触发 GM0 返回操作。遇到必须处理的选择或正在生成时，沿用原业务限制，不通过观景、返回或切换输入绕过。

## 二、画面与短句的实现口径

- **舞台固定 16:9。** 横屏取设备可容纳的最大 16:9 区域并居中，超宽屏左右留黑，较窄屏上下留黑。气泡和常驻按钮以舞台为定位边界。只有场景图按宽等比缩放、居中上下等量裁切。例如 1216×832 取中间 1216×684，上下各裁 74 像素；真实素材按自身比例计算。地图的可点区域须与底图一致，3D 画布随视窗重排。
- **CG 完整显示。** 对现有窄于舞台的 CG，等比居中、高度撑满主视窗；两侧透出的**下层场景**做毛玻璃。CG 本体清晰，不裁、不拉伸、不复制 CG 铺边。若素材比 16:9 更宽，以完整显示优先。切换或关闭 CG 时同时更新或撤掉侧边模糊。
- **人物与气泡。** 横屏立绘相对当前横屏适当放大；双人向左右分开，保持站位稳定。气泡使用半透明底，让正文可读、底图可见。大小、间距和透明度用单／双人、明／暗背景及手机矮屏实图确定，不预定未经比较的数值。
- **先读段落，再切短句。** 沿用台本解析器区分正文与 `|` 后的场景、表情、CG。只对段内正文切句：优先 `。！？!?` 等句末符号，连续标点与闭引号归前句，不按每个逗号强拆。无句末符号的超长句再按次级停顿或长度拆；不跨原段拼句。每句引用所属帧及原文起止位置，不重新推断表情。例：`她回头：“谁？！”门开了。` → `她回头：“谁？！”`、`门开了。`，两页同画面。全文与历史保留原文。

## 三、当前实现与改造边界

| 所有者 | 当前行为与维护边界 |
|---|---|
| [主视窗布局](../module/game-styles-layout.css)／[气泡样式](../ui/stage-story.css) | 地图、地点、等待和故事共用 16:9 边界。地图标签和 SVG 热区与场景图同步缩放、裁切，HUD 与弹窗留在可视区。竖屏保留原布局。 |
| [气泡](../module/stage-story.js)／[显示租约](../module/presentation-adapter.js) | 刷新正文、读档或转入横屏时进入舞台；主动返回操作后，同轮刷新不抢回阅读。只用 `#main-viewport` 的 GAL 渲染器。退出阅读归还原节点和租约。 |
| [阅读计划](../module/presentation-plan.js)／[回听](../module/stage-story-media.js) | 冻结帧和原文是事实来源；短句、缓存声音和旧单元游标通过原文范围对应。不为显示切句修改旧档计划与哈希。 |
| [正文与事件](../module/game-ui.js)／[回合流程](../module/pipeline.js) | 历史只读；当前事件复用原卡片及结算。桌面和手机共用原输入、发送、重生成和中断。等待期间切横竖屏只迁移原按钮，不重发。 |

**删除边界：** 独立绘卷宿主、菜单动作桥、事件借用、等待遮罩、阅读器播放控件及专用样式已删除。共享计划、历史、缓存、竖屏演出、3D 换场和原玩法入口保留。本次不新增存档字段、外部依赖或网络服务。

### 验收清单

| 实际操作 | 必须发生；失败代价 |
|---|---|
| 翻同段多句、引号、连续标点、超长句和相邻不同表情的段落；重听当前句 | 不漏字、不重复，文字、声音和画面对应；否则会错读、错图。 |
| GM0 从短句／全屏全文返回操作，再点书本；在无帧回合重复 | 可进入操作，返回到正确故事位置，无帧也能输入；否则可能无退出或返回入口。 |
| GM1 全文时点齿轮和任务，进设置，再走原返回门派流程 | 菜单可达，点击不穿透、不意外切地图；否则阻断下山操作。 |
| 长文滚至随机事件；切历史再回来；分别处理战斗与支线 | 当前选项可见且只提交一次，历史不可派发行动；否则推进错误回合。 |
| 手机输入中文并切回，发送、重生成、中断；期间开弹窗或旋屏 | 按原规则保留草稿与禁用态，无误发、双发和旧回合覆盖；否则可能产生额外请求或破坏对话。 |
| 古风／扁平、普通／像素立绘、CG 开关、2D／3D 下观景往返 | 实操截图审查黑边、CG 全图与侧边模糊、双人脸部、字色、菜单和地图热区；否则会遮脸、难读或点错。 |
| 旧档重读及横竖屏往返；安卓真机弹出再收起键盘 | 原文与续读位置不丢，输入与中断可点，竖屏无回归；浏览器模拟和真机结果分别登记。 |
