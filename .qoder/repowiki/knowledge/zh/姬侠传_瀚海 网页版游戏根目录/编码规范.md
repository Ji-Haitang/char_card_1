- HTML 页面通过 `<script src="module/xxx.js">` 按依赖层级顺序引入，禁止循环依赖，顶层页面只暴露 onclick 内联函数到 window。
- 对外暴露的公共 API 统一挂载到 window 命名空间（如 apiService、storageService、pipeline），避免隐式全局变量。

- 数值变更一律通过 checkAllValueRanges() 校验后保存，技能装备前检查记忆点上限。
