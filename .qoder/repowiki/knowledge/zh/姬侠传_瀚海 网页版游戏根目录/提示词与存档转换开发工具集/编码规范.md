- CLI 脚本统一使用 `process.argv[2]` 获取输入路径，缺失时打印用法并 `process.exit(1)` 退出。
- 对 LLM 输出的结构化文本采用 `<TAG>...</TAG>` 正则提取模式，封装为 `extractTag(text, tag)` 函数复用。
- 中文数字到阿拉伯数字的转换集中在 `cnNum` 与 `weekLabelToNum` 两个函数中，多处脚本重复实现相同逻辑，体现「复制粘贴式」工具脚本风格。
- 生成的 JS 模块一律包裹在 `(function(){ ... window.* = ... })();` IIFE 中，并通过 `window.PROMPT_*` 与 `*_REGISTRY` 数组暴露给浏览器端加载。
- txt 源文件路径与对应变量名通过 `{ varSuffix, file, name }` 配置表集中声明，避免在循环体内硬编码字符串。
