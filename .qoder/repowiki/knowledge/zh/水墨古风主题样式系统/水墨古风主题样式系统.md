## 样式体系概述

本项目采用**双层CSS架构**：基础样式层 + 主题覆盖层，实现「现代游戏UI」与「水墨古风」两套视觉风格的无缝切换。

### 核心文件与职责
- `module/game-styles.css` — 基础样式（布局、响应式、组件骨架），定义所有类名与结构
- `module/game-styles-theme.css` — 古风主题覆盖层，通过CSS变量+`!important`覆盖基础样式
- `index.html` — 入口文件，同时加载两份CSS，通过JS动态切换主题

### 设计系统与约定

**1. CSS变量主题系统**
```css
:root {
    --paper-base: #f4f0e6;      /* 宣纸底色 */
    --ink-black: #1a1a1a;       /* 焦墨 */
    --accent-red: #a93226;      /* 朱砂 - 战斗/强调 */
    --accent-cyan: #2471a3;     /* 靛青 - 互动/选中 */
    --accent-gold: #b7950b;     /* 藤黄 - 金钱/高亮 */
}
```

**2. 响应式策略**
- 根字体大小断点：`16px → 14px(≤768px) → 12px(≤480px)`
- 间距/字号统一使用 `clamp()` 函数实现弹性缩放
- 视口单位(`vw`)用于场景标题等需要随屏幕变化的元素

**3. 组件命名规范**
- 场景容器：`.scene` + `.active` 控制显隐
- 弹窗系统：`.modal` + `.modal-content` + `.modal-btn`
- 状态栏：`.status-display` 内分 `.date-display` / `.mood-display` / `.action-points-display`
- 按钮族：`.control-btn`(底部)、`.scene-btn`(场景)、`.back-btn`(返回)

**4. 古风主题特色**
- 纸张纹理：SVG data URI 作为背景图案
- 竖排文字：`.scene-title` 使用 `writing-mode: vertical-rl`
- 印章风格按钮：直角边框 + 墨水扩散动画(`@keyframes ink-spread`)
- 卷轴质感：双层边框(`--border-double`) + 硬阴影(`--shadow-hard`)

**5. 交互反馈约定**
- 悬停：`transform: translate(-1px, -1px)` + 阴影增强
- 按下：`transform: translate(1px, 1px)` + 阴影归零
- 禁用态：`opacity: 0.6` + `cursor: not-allowed`

### 开发约束
- 新增组件需先在 `game-styles.css` 定义基础样式，再在主题文件中覆盖
- 所有颜色必须使用CSS变量，禁止硬编码色值
- 字体栈优先使用楷体系(`Kaiti`, `STKaiti`)，正文可读性要求时使用无衬线体
- 滚动条样式通过 `::-webkit-scrollbar-*` 伪元素统一定制
